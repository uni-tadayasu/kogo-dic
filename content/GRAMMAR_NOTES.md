# 文法・文章変換・詩歌補助の設計

## 実装の範囲

`dist/language.js` はブラウザーで動く辞書照合・文法規則による補助モジュールです。自由文を文脈まで解釈する言語モデルは使っていません。全入力を翻訳できると表示しないでください。未解析の箇所は元の表記を残し、候補・対応語・曖昧さを返します。`coverage` は収録語との照合文字数の割合（0〜1）であり、翻訳精度ではありません。

### API

- `analyzeText(text, direction, entries)`：`direction` は `classical-modern` または `modern-classical`。戻り値は `output`, `summary`, `tokens`, `notes`, `coverage`, `limitations`。各 token は `surface`, `lemma`, `meaning`, `pos`, `form`, `entryId`, `note`, `output`, `known` 等を持ちます。
- `conjugate(entry)`：活用語なら六活用形の `{form, value, connection}` 配列。対応しない語は空配列。歴史的仮名遣いの読みを基準に活用形を作ります。助動詞は品詞が「助動詞」の場合に専用表を用います。
- `speechText(text, entries, mode='modern')`：登録した読みと固有名詞で発話用文字列を作成します。`raw` は置換なし、`historical` は辞典の歴史的仮名表記を使います。いずれも古代の実際の発音の復元ではありません。音声合成器の同音異義語・アクセントの完全な制御は保証できません。
- `analyzePoem(text, type, reading?, entries?)`：`type` は `haiku`, `senryu`, `tanka`。改行または `/`、`／` で句を分けます。所定の数の空白区切りも受け付けます。作者のかな読みがないまま漢字が残る行は音数を `null` とし、定型達成を断定しません。
- `poemExamples`：俳句・川柳・短歌各一作の自作例（本文・読み・参考解説）。他者の作品は転載していません。

### 注意事項

動詞・形容詞等の活用表は学校文法の基本形です。時代・文体による異形、音便、上代特殊仮名遣い、あらゆる複合語は網羅しません。係り結びや「ぬ」「なり」の判別は注意を返し、確定した構文解析とはしていません。辞書の代表語義だけでは自然な文章を保証できないため、UI は必ず「参考候補」の表示を伴わせてください。

現代語の「です」を「なり」に置くことは丁寧さの再現になりません。この相違は候補の注記にも含めています。過去「き・けり」、意志・推量「む」などは、複数の可能性を注記します。

詩歌の音数は現代標準的な読みの拍を数えます。拗音・外来音の小書き仮名は直前の仮名とまとめ、「っ・ん・ー」は各一拍。単独の小書き仮名は仮に一拍として要確認とします。漢字・数字・ローマ字・繰り返し記号が残る場合、読みの指定を求めます。本文と読みの行数が違う場合も定型判断を保留します。自動的に五七五へ切り分けて「完成」とする処理はありません。

季語は基本的な語の一致による候補です。例えば「春風」の中の「春」を重ねて数えませんが、語彙だけでは季語の用法を確定できません。季重なり・切れ字の複数使用・字余りを一律に誤りとしません。季語が未検出でも無季の判定や未収録語を否定しません。川柳・短歌には季語を必須にしません。

## 検証対象

動詞九種、形容詞二種、形容動詞二種、助動詞「き・ず・しむ・なり」の基本形。例句三種の音数（5/7/5、5/7/5、5/7/5/7/7）。漢字だけの句は保留、かな読みを指定すると計算、促音・長音・拗音・単独小書き仮名を確認。翻訳は未知語を保持し、過去・打消の形を返すことを確認する方針です。
