# 古語辞典｜葛西書店

黒板とチョークをモチーフにした、PC・スマートフォン・タブレット対応の古語学習サイト。検索、独自の語釈・要約・創作用例、活用表、読み上げ、自由な手書き黒板、俳句・川柳・短歌の創作を備えています。

## 起動・検証

Node.js 22以上を使用します。依存パッケージのインストールは不要です。

```sh
node scripts/check.mjs
node scripts/build.mjs
python -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開きます。ファイルを直接開く方式ではJSONの読込やWeb Workerに制約があるため、HTTPで提供してください。

## 公開

`.github/workflows/pages.yml` が `main` への変更を検証し、`dist` を GitHub Pages に自動公開します。初回はリポジトリ Settings → Pages → Source を **GitHub Actions** に設定してください。ワークフロー・公開先の権限はリポジトリ設定に従います。

公開URLは GitHub の `github-pages` environment と Actions のデプロイ結果を参照してください。

## 機能

- 見出し、歴史的仮名遣い、現代の音読、現代語、解説から検索。品詞・しおり絞り込み。
- 意味、要約、複数の語義、創作用例、使い方、注意、関連語、対応する活用表。
- 日本語音声の選択、速度調整、一時停止、項目移動、連続再生、ループ。利用者による読み方の登録。
- 双方向の語彙・文型変換と、語ごとの辞書照合・解説。
- 俳句・川柳・短歌の音数、読み仮名、季語・切れ字候補、推敲の手がかり、作品帖。
- 自由な筆記、直線、マーカー、消しゴム、筆圧、Undo/Redo、複数黒板、方眼、PNG出力。
- 6,603字形の手書き候補を端末内で照合。一文字ずつ選んで検索・文章入力。
- しおり・黒板・作品を端末内に保存。JSONバックアップの書出し・追加復元。

## 収録範囲・精度

これは独自の学習用語釈を収録する辞典です。市販古語大辞典の完全収録版ではなく、全時代・全古語・全用法の網羅を意味しません。収録数は実データから画面と `dist/data/edition.json` に表示されます。

文章変換は内蔵辞書・文型・活用による参考候補です。生成AIによる長文の文脈理解ではありません。未対応文字列は保持し、主語や敬意の方向などの解釈を確定しません。学校文法の基本形を扱い、すべての時代差・異形・音便を網羅しません。

手書き入力は楷書の一文字候補で、くずし字・連綿・長文OCRは対象外です。表示スコアは正解確率ではありません。筆圧・入力頻度は端末のハードウェアとOSに依存します。

読み上げは日本語のWeb Speech APIを利用します。読み仮名と利用者の読み辞書を優先しますが、発音・アクセント・バックグラウンド再生は端末音声に依存します。

漢字や読みが不確かな作品は音数を確定しません。読み仮名を入力してください。字余り・無季・自由律を一律に誤りとは扱いません。
